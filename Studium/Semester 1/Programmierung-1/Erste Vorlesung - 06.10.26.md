# -Compiler
- Verifying syntactical correctness, analyzing program structure, transforming into internal representation (scanner/parser)
- Creating machine code from internal representationn; possibly optimizations (code generator)
# -Linker
- Sometimes considered part of the compiler
- Creates complete executable program (on Windows: .exefile) from different, already compiled parts (Object files, .o files, possibly further libraries)
- Adds predefined libraries to the machine code that was produced by the compiler
- Enables seperate/distributed program development
